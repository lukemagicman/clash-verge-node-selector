# Clash Verge 中间节点选择器

一个在本机运行的 Clash Verge Rev 配置辅助工具。它从当前订阅中找出节点、测试 TCP 连接延迟，让你选择一个中间节点，并将 SOCKS5 或 HTTP 出口代理安全写入增强配置。

> 本项目不会上传订阅内容、节点名称、出口 IP 或账号密码。

## 能做什么

- 自动读取 Clash Verge Rev 当前启用的订阅
- 识别常见 YAML 节点格式，并过滤常见占位节点
- 对节点执行 TCP 握手测试，按延迟显示列表
- 为 SOCKS5 / HTTP 出口代理选择可选的 `dialer-proxy` 中间节点
- 将出口代理写入关联增强配置的 `prepend` 段
- 每次写入前创建普通备份和带时间戳的备份

## 使用方法

1. 下载或克隆本仓库。
2. 保持 `中间节点选择器.bat` 与 `中间节点选择器.ps1` 在同一文件夹。
3. 双击 `中间节点选择器.bat`。
4. 等待节点测速结束，输入中间节点编号；若不需要中间节点，直接回车。
5. 输入出口地址、出口类型和备注名。
6. 重启 Clash Verge Rev 使配置生效。

## 出口地址格式

| 输入示例 | 说明 |
| --- | --- |
| `socks5://user:pass@1.2.3.4:443` | SOCKS5，含账号密码 |
| `http://user:pass@1.2.3.4:8080` | HTTP，含账号密码 |
| `user:pass@1.2.3.4:443` | 无协议前缀；运行时选择类型 |
| `1.2.3.4:443` | 仅地址与端口 |
| `[2001:db8::1]:443` | IPv6 地址；必须使用方括号 |

端口省略时默认使用 `443`。账号或密码中若包含 URL 特殊字符，请使用 URL 编码。

## 安全与隐私

- 只读取和修改本机 Clash Verge Rev 配置目录。
- 不包含、不收集、不上传订阅链接、节点、IP 地址、用户名或密码。
- 用户输入及节点名称会进行 YAML 单引号转义，避免因特殊字符损坏配置。
- 写入异常时会停止并提示错误；原配置会先备份为 `.bak` 与时间戳备份文件。

## 注意

- 测速结果是 TCP 建连延迟，只表示连通性和大致响应速度，不等同于代理实际下载速度。
- 请确认出口代理服务商允许通过中间节点使用。
- 本工具面向 Clash Verge Rev 的默认数据目录；其他 Clash 客户端可能需要调整路径。
